## 生成逐篇索引

工具：tools/build_siyuan_catalog.py，仅依赖 Python 标准库。在仓库根目录执行：

```bash
python tools/build_siyuan_catalog.py
```

指定思源数据目录：

```bash
python tools/build_siyuan_catalog.py --root /path/to/siyuan/data
```

如果本地另有未纳入 Git 的附件目录，可额外指定：

```bash
python tools/build_siyuan_catalog.py --root /path/to/siyuan/data --assets-dir /path/to/assets
```

默认输出到 catalog/generated/：

| 文件 | 用途 |
|---|---|
| documents.csv | 逐篇路径、标题、目录、主题、解析状态、哈希及正文检索片段 |
| topic_index.csv | 按主题展开的文档导航 |
| asset_references.csv | 文档引用的附件路径与本地映射状态 |
| catalog.md | 本次扫描概况、目录统计和重复文件清单 |
| asset_audit.md | 附件引用审计概况 |

如需把思源内部目录 ID 显示为笔记本名称，可创建 JSON 映射文件并通过 --notebook-map 传入，格式为：

```json
{
  "笔记本目录ID": "笔记本显示名称"
}
```

## assets 的处理边界

仓库根目录的 .gitignore 明确排除了 assets/。因此：

- Git 仓库扫描只能统计文档中的附件引用，不能证明本地附件存在或缺失；
- 用户本地的附件不应为了生成索引而被复制或上传到公开仓库；
- 未传入 --assets-dir 时，附件状态标记为 NOT_CHECKED，不代表附件缺失；
- 传入本地附件目录后，工具才会尝试将引用路径映射到本地文件。

## 内容使用边界

仓库内的使用说明将资料定位为个人学习参考，并对商业及医疗用途作出限制。仓库根目录未发现开放许可证声明。请在再分发、改编、商业使用或公开发布前逐项确认原始资料的版权与授权。

本索引不提供医学真实性背书。网络整理、课程转写、图鉴说明和未经校勘的内容必须与可靠版本及现代证据交叉核对；不得将自动分类结果直接用于诊断、处方或临床决策。
